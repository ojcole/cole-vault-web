# cole-vault-web

A browser-based password generator with config import from the Password-Manager desktop app (Electron/React).

## Features

- Generate secure passwords with configurable length and character sets
- Manage multiple site profiles
- Import configs from the [Password-Manager](https://github.com/ojcole/Password-Manager) desktop app
- Config versioning with backwards-compatible migrations

## Getting Started

### Development

```sh
npm install
npm run dev
```

Open [localhost:5173](http://localhost:5173).

### Build

```sh
npm run build
```

Output is in `build/`. Preview with `npm run preview`.

### Tests

```sh
npm test
```

### Lint / Format

```sh
npm run lint
npm run format
```
